📊 Análise Científica de Treinamento

Análise estatística avançada dos resultados de treinamento

ℹ️ Informações do Treino

PRINCIPAIS

Gráficos para Texto Principal

1️⃣ Curva de Loss (Treino × Validação)

Interpreta: Convergência do modelo. Linhas próximas = boa generalização. Val subindo + Train caindo = overfitting.

2️⃣ Gap de Generalização (val_loss − train_loss)

Interpreta: Quanto o modelo "descola" do treino. Gap pequeno = robusto. Gap crescente = memorização.

3️⃣ Accuracy Top-1 × Epoch

Interpreta: Velocidade de aprendizado. Platô precoce = limitação do modelo/dados.

COMPLEMENTARES

Gráficos para Apêndice

4️⃣ Accuracy Top-5 × Epoch

Interpreta: Capacidade de "chegar perto" da classe. Top-5 alto + Top-1 baixo = classes semelhantes.

5️⃣ Diferença Top-5 − Top-1 (Ambiguidade)

Interpreta: Grau de ambiguidade. Δ grande = classes parecidas. Δ pequeno = separação clara.

6️⃣ Estabilidade do Treino (Variância - Janela 10 epochs)

Interpreta: Oscilação do aprendizado. Alta variância = instável. Baixa variância = convergência sólida.

7️⃣ Learning Rate Schedule

Interpreta: Evolução do otimizador. Queda brusca = refinamento fino. LR alto com loss alto = instabilidade.

8️⃣ Tempo por Epoch (Eficiência)

Interpreta: Custo computacional. Tempo constante = estável. Picos = gargalo I/O/GPU.

9️⃣ Correlação Accuracy × Loss

Interpreta: Relação entre erro e acerto. Correlação negativa forte = saudável. Disperso = inconsistente.
